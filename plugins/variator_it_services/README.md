# variator_it_services (plugin)

IT services: software outsourcing and the IT company as a system.

| Need | Use |
|---|---|
| Templates | `delivery_model` (in-house / nearshore / offshore), `company_model` (7 factor blocks, chains, levers) |
| Code metrics | `codebase.component_metrics`, `codebase.architecture_report` |
| Backlog | `jira_synth.generate`, `estimation.fit_effort` / `estimate` / `release_forecast` / `rice_ranking` |
| Metric catalog (offline) | `metrics_catalog.search` / `metric` / `cite`; data `data/sdlc_metrics.json`; rebuild `scripts/build_sdlc_catalog.py` |
| RAID | `raid.raid_summary`, `raid.raid_patch` |
| MCP tools | `it_services_*` (see `docs/knowledge/it-toolkit.md`) |
| Rule packs | `rules/outsourcing_basic.yaml`, `rules/company_basic.yaml` |
